# Sunrise Villa — Lebong, Darjeeling 🌄

Homestay booking website for **Sunrise Villa**, Golai Bazar, Lebong, Darjeeling.

## Pages
- Home (`/`) — rotating photo hero, availability check
- Rooms, Gallery, About, Contact
- Book (`/book.html`) — booking form
- Admin panel (`/admin.html`) — owner login, bookings dashboard

## Run

```
start-server.bat
```

Then open `http://localhost:3000` (or `http://<your-ip>:3000` from phone on hotspot).

No dependencies — plain Node.js.

## Booking data
Saved to `data/bookings.json`.

## Admin
Default login: `admin` / `sunrise@2026` (change it in `server.js`).
